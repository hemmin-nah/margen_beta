# MARGEN 1.13.1 Beta

## Exportación JSON por libro

- El botón de exportación JSON permite elegir entre **Biblioteca completa** y **Un solo libro**.
- La copia completa conserva exactamente el formato de backup de MARGEN existente.
- Un libro individual se exporta como `MARGEN_BOOK` formato 1, con el libro completo y sus datos asociados.
- El formato queda preparado para una futura función **Importar libro** que añada el libro sin sustituir la biblioteca.
- Se puede escoger cualquier libro desde el selector de exportación.
- El build de Windows se mantiene sin cambios respecto al workflow aprobado.
