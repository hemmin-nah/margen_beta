# MARGEN 1.13.0 · Pizarra avanzada y atajos

## Pizarra
- Historial estructural unificado para mover, borrar, redimensionar y dibujar.
- Ctrl+Z / Ctrl+Y prioritarios en Pizarra cuando no se está editando texto.
- Los trazos libres pueden seleccionarse y moverse después de dibujarlos.
- Los sellos vectoriales siguen moviéndose como una pieza completa.
- Lienzo virtual amplio con recentrado automático para comportarse como un espacio sin límites perceptibles, siguiendo la filosofía de Genealogía.
- Espacio + arrastrar activa temporalmente la mano, incluso con Lápiz seleccionado.

## Atajos básicos
- V: Selección.
- B: Dibujar.
- T: Texto.
- Espacio + arrastrar: mover pizarra.
- Ctrl+Z / Ctrl+Y: deshacer / rehacer.
- Ctrl+A: seleccionar todo en Pizarra.
- Ctrl+C / Ctrl+V: copiar / pegar selección.
- Supr: eliminar selección.
- Esc: cancelar y volver a Selección.
- Ctrl+G: agrupar selección (se conserva el atajo existente).

## Ayuda
- Nueva pantalla «Atajos de teclado» dentro de Conoce MARGEN, situada antes de «Ver presentación inicial».

## Compatibilidad
- Las pizarras antiguas se recolocan internamente en el nuevo lienzo manteniendo la misma posición visual al abrirlas por primera vez.
- La barra del editor no se modifica.
- El workflow de Windows no se modifica.
