# MARGEN 1.10.1

Actualización de pulido posterior a la validación de 1.10.0. No cambia el modelo de datos ni la carga bajo demanda.

## Editor
- Los nombres de personajes y escenarios de «Consulta rápida» ya no se recortan con puntos suspensivos: pueden ocupar varias líneas y la lista conserva scroll.
- Al abrir Fichas, Referencias o Buscar en libro, la fila «Editar / Lectura continua / Escritura amplia», «Buscar en libro» y «Novela / Guion» se alinea con el espacio real que queda para el editor, igual que el papel y la barra de formato.
- En ventanas estrechas, donde los paneles pasan a la parte inferior, se conserva el comportamiento responsive anterior.

## Sin cambios
- La carga bajo demanda, guardado incremental, copias JSON completas y diccionarios de 1.10.0 permanecen sin cambios.
