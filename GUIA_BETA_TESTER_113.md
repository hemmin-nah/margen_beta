# Prueba rápida MARGEN 1.13

En una copia de prueba de un libro:

1. Abre una Pizarra antigua y comprueba que visualmente aparece en el mismo sitio.
2. Desplázate mucho con **Espacio + arrastrar** y confirma que no encuentras un borde cercano.
3. Dibuja un trazo con **B**, vuelve a selección con **V**, selecciónalo y muévelo.
4. Haz **Ctrl+Z** y **Ctrl+Y** varias veces alternando dibujo, movimiento y borrado.
5. Mueve una nota, pulsa Supr y recupera con Ctrl+Z.
6. Prueba **T** para crear texto y **Esc** para volver a selección.
7. Abre **Conoce MARGEN → Atajos de teclado** y comprueba que la lista se entiende.
8. Comprueba que Editor, Fichas, Cronología, exportación y Biblioteca siguen comportándose como en 1.12.3.

Si algo falla, anota exactamente la secuencia de acciones (por ejemplo: «dibujar → mover → seleccionar nota → Supr → Ctrl+Z»), porque el orden ayuda mucho a reproducir problemas de historial.
